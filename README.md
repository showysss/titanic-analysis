# Titanic Survival Analysis

## Overview
タイタニックの乗客データを用いて、生存率に影響する要因を分析した。

## Hypothesis
- 女性や子供が優先されるのではないか
- 上位クラスの方が生存率が高いのではないか
- 家族連れの方が生存率が高いのではないか

## Analysis
以下の観点で分析を行った：
- 性別（sex）
- 年齢（age）
- 客室クラス（pclass）
- 運賃（fare）
- 家族構成（alone）

## Findings
- 性別が最も大きな影響を持ち、女性の生存率が高い
- 上位クラスほど生存率が高い
- 子供は優先される傾向がある
- 家族連れの方が生存率が高い
- 運賃の影響はクラスと関連している可能性が高い

## Discussion
生存率は単一の要因ではなく、性別・クラス・年齢など複数の要因が組み合わさって決定されていると考えられる。
